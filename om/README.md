# om: Sovereign Core in seeded Omega

First-party Omega (`.om`) replacements for parts of Sovereign Core, built by the seeded Omega compiler
(`seed/out/omc` from omega-mv, pinned by sha256 in each test). Rust stays the production path until a
replacement passes parity and real-execution tests against it ([#748](https://github.com/aien-dev/aien-sovereign-core-mv/issues/748),
aien-architecture-mv#300).

| Path | What it is | Status |
|---|---|---|
| `effects/world.om` | The restart world check of the effect ledger: reads the target file, hashes it, decides DONE / NOT_DONE / UNRESOLVED like `effects::state_from`, and writes the reconcile record text and its sha256 like `effects::reconcile_text`. | Byte-identical to the Rust on 24 fixtures (`effects/run.sh`). Not wired into the daemon. |
| `tur-ledger/tur-ledger.om` | Aienet-0 test-credit ledger CLI: v2 genesis pins issuer, independent verifier and account/node policy. Canonical mutations require issuer signatures; settlement also requires verifier authorization over signed-job, result and attestation digests and the reserved quote. Single-writer hash chain, fsync, recovery, integer conservation and exactly-once settle remain. See `tur-ledger/README.md`. | Host admission/durability tests and guard mutants in `tur-ledger/check.sh`; no wallet, Core RPC or public economic qualification. Historical unsigned v1 receipts remain historical. |
| `flint/manifest.om` | Bounded manifest reader for the pinned Flint BF16 checkpoint (RecursiveSI/flint `2a247be0`, Core #802 P0): admits config, index and every safetensors header, refuses anything outside the pinned layout with a distinct exit code, prints the tensor inventory TSV. See `flint/README.md`. | Host: `flint/check.sh` 89/89 with the downloaded checkpoint and the operator arm (38 refusal fixtures, 25 guard mutants; 70 without the operator arm). |
| `flint/ops.om` | Flint P0 forward operators recomputed in f64 from the real BF16 weights (Core #802): RMSNorm, q/k/v with q/k norm and RoPE, attention with sinks and the 513-key window, the sigmoid top-6 router, shared expert, routed expert and MoE block, each within twice a first-order bound on the reference's f32 error (`flint/test/TOLERANCE.md`). | Host: in `flint/check.sh` 89/89, 9 operator fixtures and 2 router controls against the pinned transformers reference (fixtures sha256 pinned), 6 forward mutants caught. Layer, logits, generation, bf16-activation parity and GPU NOT_RUN. |
| `golden/golden.om` | Golden-token recorder and comparator (Core #853): writes greedy request bodies, takes `usage.aien_token_ids` from engine replies into an `aien-golden-record/1` file with the engine sha256, model repo and revision, sampling, prompts sha256, host id and UTC time; `cmp` reports the first divergence index per prompt. `golden/fake.om` is a test-only HTTP responder. See `golden/README.md`. | Host: `golden/check.sh` 27/27 (9 comparator arms on synthetic fixtures, 15 recorder arms against `fake.om`, 3 guard mutants). No real reference recorded. |
| `vendor/sha256.om` | Incremental SHA-256 in Omega, vendored from benchmarks-mv. | Exercised through `world.om` and `tur-ledger.om`. |
| `vendor/ec.om` | Native Omega ECDSA P-256/P-384 verification, byte-identical to omega-mv `6999fa9e6dae4847c155ef4eacaece74f491d3ca` `om/tls/ec.om`. | P-256/SHA-256 strict DER verification used by `tur-ledger.om`; OpenSSL is a test-only signing oracle, not a runtime dependency. |
| `vendor/json.om` | Seeded JSON tape parser, byte-identical to omega-mv `bf54b19fa590e8ae925c0e80815516dbf41e7326` `seed/json/json.om`. | Used by `flint/manifest.om` for config and safetensors headers. |
| `residency/residency.om` | MoE expert residency simulator (sc#630 question, sc#633 hints): replays a recorded router trace against a per-layer expert cache, and (when L*E <= 65536) one cache shared by all layers in serving order, and counts hits and misses for LRU and Belady OPT at 25-90 % resident. An optional hint section (H <= 16 predicted experts per step and layer) adds two shared-LRU replays with prefetches that count demand misses and prefetches used and wasted: hlru (a hint marks its expert used) and hcold (a hint only protects its expert for the step; a fetched one enters at the LRU end). Reads up to T*L = 1000000 rows. | Host only. Matches the Wolfram LRU/OPT/hinted-LRU oracle (`residency/fixtures/oracle.wl`) on a real 35B trace slice and a synthetic trace with and without hints; 15 refusals, 3 boundary checks, 2 hint-line gates, 4 hint invariants and 10 mutants checked (`OMEGA_OMC=<seed omc> bash om/residency/run.sh`). Not wired into the pager. |

Run: `OMEGA_OMC=<path to seed omc> bash om/effects/run.sh` (needs the offline cargo cache for the Rust
reference, `crates/aien-runtime/examples/om_world_reference.rs`).

Not covered yet: the confined check (`confined_world_state`, which needs a descriptor-relative open
with resolve flags in Omega), the journal write, ledger rebuild, and the steps before the effect
(objective, inference, typed tool, approval). The list with owners is in #748.
